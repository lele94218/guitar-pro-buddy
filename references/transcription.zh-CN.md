# 转谱与 Guitar Pro 操作

[English](transcription.md) | **简体中文**

## 读懂原谱再编码

- 查看教材自己的记谱说明。不要把 `×` 一律当作闷音：《弹指之间》曾用它表示“按上方和弦手型弹这一弦”；其他谱可能确实表示闷音。
- 列出拍号、速度、调号、调弦、变调夹、弱起、一二房和 D.S./Coda 的路线。反复可以保留，也可以按要求展开；不能在两种表示间无说明地改变播放结构。
- 字母和弦名与具体弦品不是同一信息。若原书有六线谱，保留实际弦品；只有旋律时，选择连贯的乐句指法并说明这是编配。
- 合并左右双录吉他前，比较音符、节奏及奏法。相同材料可合并；同时发生且无法清晰表示的部分按要求分 Rhythm/Lead，不靠删音解决冲突。
- OCR 只辅助定位文字、和弦或小节。谱线、延音、连奏、装饰音与鼓谱符头仍需针对性看图。

## 可复用的数据路线

既有工作流使用项目 venv 的 `guitarpro`（PyGuitarPro）生成 `.gp5`，由 Guitar Pro 打开后另存 `.gp`。不要仅改扩展名，也不要假定该库可直接读写 GP8 原生容器。

编码时保留独立的结构化小节数据，避免把一次性的 GUI 点击当作唯一记录。按需要记录：

- 小节号、轨道、声部、起拍、休止、基础时值、附点、连音比例。
- 弦号/品位或实际音高、延音起止、击勾弦、滑音、装饰音、推弦曲线、颤音。
- 歌词音节、和弦位置、反复与段落说明。

已用过的 PyGuitarPro 细节需结合当前安装版本及回读结果核对：

- `Duration(value=8, tuplet=Tuplet(enters=3, times=2))` 表示八分三连音；六连音与三连音可以数值等长但记谱分组不同，别只按总时长简化。
- `note.effect.hammer` 标记通往下一个音的连奏，不要把一组三音的三个音全标成继续连奏。
- 击勾弦与跨小节延音不是同一个字段；不能把持续音当成重新拨弦。
- 该工作流中 BendPoint 的 `value` 以四分之一音计：全音推弦为 4。修改推弦时同时核对显示与目标音，不凭参数名猜单位。
- 普通 4/4 小节在已用库版本中是 3840 ticks，但校验器应按拍号计算，不把它套到弱起或变拍小节。
- 人声的实际 MIDI 音高和谱面八度分别核对。不要看到谱面偏低就同时修改实际音高与移调设置，导致双重修正。
- 鼓轨的开放/半开放踩镲、Crash 与 Ride 以当前 GP 乐器映射及原谱图例为准。不要把 In Bloom 中观察到的符头或扩展 MIDI 编号固定成所有谱的规则。

回读检查包括每个非空声部时值、轨数、音符数量、弦品与效果。装饰音不能重复计入小节总拍数。若源和导出文件使用不同共享 ID，按实际小节展开比较音乐事件，而非仅比较文件大小或对象数量。

## macOS 应用操作

- 优先通过 System Events 的辅助功能树识别窗口、菜单与对话框；菜单随应用版本和语言变化，先查再点。
- 只读检查当前窗口及 File 菜单可用性。不能保存的谱若按用户授权手工转录，以显示的原谱为依据，不把下载来的另一个版本冒充结果。
- 先打开候选 GP5/GP，确认音轨，再另存原生 GP。原生文件可作 ZIP/GPIF 检查，但不要为普通导出引入不必要的 XML 编辑。
- 导出 PDF 前查看小节密度、空白和弦图、和弦文字与尾页。System Layout 的数值输入曾未实际生效；每次读回控件数值，不靠点击成功推断设置成功。
- `E+` 曾被显示成 `E♯`，可在语义不变时使用 `Eaug`，并检查实际显示。不要无依据替换所有含 `+` 的和弦名。
- 锁屏、屏保或辅助功能不可用时先确认真实状态，保留进度；不要反复点击或断言一定是锁屏。能独立完成的数据工作继续做，GUI 步骤待桌面可操作后恢复。
- 若已获授权临时防休眠，只在导出期间启用，完成即结束；不要改变长期系统设置。

## 复用已有项目

优先检查用户已有的转谱项目，按需复用经过验证的数据结构、奏法处理和往返校验。旧脚本可能有过时路径、全尺寸图片或特定曲目的假设；先读有关函数，不直接批量运行，也不擅自搬迁项目。
